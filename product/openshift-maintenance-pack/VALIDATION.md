# Preview validation and limitations

Version: 0.1.0-free-preview

Completed locally:
- Python standard-library implementation; no runtime dependency install.
- Twelve offline tests: fixed mocked queries, generic failure handling, selected-field projection, cross-cluster/origin rejection, time ordering, hash tampering, inventory removal, no-overwrite behaviour, private file permissions and synthetic result interpretation.
- Offline example generation and report review.

Not completed:
- No real `oc` command, authentication, permission validation or cluster capture.
- No live OpenShift release/distribution compatibility test.
- No upgrade, backup/restore, application regression or security assessment.
- No customer usability test, payment setup, purchase or revenue validation.

This free preview must not be described as live-tested, production-ready, a comprehensive readiness assessment or a compliance guarantee. Synthetic observations are clearly marked and are not collected customer evidence.
